# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
* リモートリポジトリ

  Githubなどネット上で複数人で共有するためのファイルやディレクトリの状態を記録する場所
* ローカルリポジトリ

  開発者一人一人が使用するために自分のPC上に配置するためのリポジトリ

## プッシュとマージの違いは何でしょうか？
* プッシュ

  ローカルリポジトリで作成した内容をリモートリポジトリに反映すること
* マージ

    別のブランチの作業内容をブランチに取り込むこと

## コミットとプッシュの違い
* コミットとは変更履歴を残すためにおこない、またコミットしたところからやり直すこともできます。それと比べてプッシュは、今まで行って来たことをローカルからリモートに反映させることです。

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
* 変更した内容がわかりやすいように書いてあげると良い。また「プレフィックス」と呼ばれるメッセージの先頭につけるラベルがある。例えば

  feat : 新しい機能の追加
  
  fix : バグや不具合の修正

  などがあるためこれらを使うことでさらに理解しやすくなる。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
* ローカルでマージするフロー

  コードのレビューを行わずにmainに反映されるためバグの発見に誰も気づかずに本番環境にアップされる可能性がある
* プルリクエストでマージするフロー

  どこを変更したのかを実装する前に書き人ができるためレビューすることができるのでミスを減らせる。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？
* 状況によって異なりますが、自分以外が書いたソースコードの内容を理解する必要があるので少しでも意図が汲み取れない内容があればソースコードを書いた人と相談しながら作業を進めて対処する。
